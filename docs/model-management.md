# 0.5 模型管理使用与设备验收

> 当前0.5已完成实现、构建和独立源码复核，可供手动设备验收；不代表设备已通过。最终APK身份以`reports/apk/result.json`和`reports/apk/status.md`为准。详细功能契约见[规划](model-management-plan.md)，实现证据见[验收记录](model-management-validation.md)。

## 多变体管理（llm-asr-xyh，当前实现中，尚未交付）

新版目标仅限兼容 Qwen3-ASR-0.6B 的七资产 MNN 部署，不是任意 MNN 架构。旧可信 v1 与目录入口保留；目录只修复旧固定部署。受控 v2 ZIP 可声明 FP16/INT8/INT4/MIXED，逐文件完整性与来源认证分开：自定义包仅证明与导入者提供的 SHA 一致，精度为声明，不能据此称量化数学/设备推理/质量已验证。

列表为可点击紧凑模型卡片：名称、声明精度、大小、当前选择、状态和 `x/7`；不默认显示文件名或 SHA。进入详情查看七文件状态、预期 SHA，以及选用、显式准备、释放、重新校验、快速恢复证明和确认删除。导入不自动切换选择；忙时维护拒绝不排队，运行中的 App/IME 请求不能被改选或删除模型打断。返回详情上一级是列表；旋转只保存模型内容键和本页操作ID，不保存 URI/proof/loaded。

每内容安装独立目录/安装UUID/持久证明；当前选择持久化，重启轻恢复不意味着 native 已加载。目录发布在替换前写耐久恢复记录；若rename后目录同步失败，尝试恢复此前目录字节/缺失状态，未确认恢复则拒绝请求准入并保留重试，重启先处理恢复记录，不把失败操作悄悄变成新选择。删除当前模型后需明确选另一个，不静默回退；不同内容不能借用同一 proof/resident。详情查看不允许 UI 线程读取文件。缓存概况和历史绑定同一内容/安装世代；较早 worker 不改变用户后来打开的详情，跨卡片不借用文件/历史，删除回调固定可见目标、安装及确认世代。ZIP 发现阶段的 sticky 清理失败保留到实际终态，真实关闭结束前不释放 owner、失败关闭不发布证明。新功能仍在 targeted 阶段，完整审查/full/签名APK/本地提交未完成，本文不构成交付声明。

## 固定 ZIP 与目录并列入口（llm-asr-7vl 历史合同）

“选择模型 ZIP 包 / 修复导入”仅接收单个 content 文件；规范、完整七元组清单与可重复 Python 标准库打包配方见[模型包格式](model-package-format.md)。ZIP32 profile 有意拒绝 DD/ZIP64/extra/comment/链接等，不能使用任意通用 ZIP。原目录入口保留。

ZIP 先落私有 archive（model 根外），完整首遍格式/CRC/可信 SHA 通过后才复用原逐文件 `.part` 发布；所有流/ZIP/Inflater/cleanup 完成后才最终全 SHA 与持久证明。不是整包原子回滚：审核前失败保原有效磁盘资产与证明（maintenance 可能卸载 resident），发布中正确文件保留，DIRTY 需重选 ZIP/目录修复。

页面在模型详情外显示最近一次导入的独立任务 ID、archive 复制/审核/清理阶段、字节、错误及清理结果；从紧凑列表导入也能看到本页取消按钮。发现尚未绑定模型时不会把文件或校验证据附到任意卡片；进程内返回/刷新概况保留导入终态。暂存目录含未知项时保留未知项及旧 `archive.part`，拒绝发生在 provider 打开前；目录流关闭成功不代表旧受管包已回收，此出口仍显示清理未完全成功，待真实关闭后才释放 owner。取消仅能作用于本页拥有的当前操作，等待真实关闭后才释放锁。落包保守预留完整模型+64MiB，最坏额外 archive+模型+64MiB 上限3,215,141,802bytes；可能更早拒绝低空间，但不先删旧模型，可显式选择目录。30分钟协作期限不硬中断 provider；取消时保 owner 和活目录到真实 IO 收尾。URI/模式不持久化，旧 picker/重建回调不能复活导入。

本 ZIP implementation 阶段尚无新 APK 交付；主机 fakes/targeted 不等系统 SAF/Binder/grant/生命周期或设备/麦克风/ASR/掉电验收，均 NOT RUN。下文0.5为历史使用记录，不重标旧 APK 为 ZIP 版本。

## 页面入口

- 转写主页：模型摘要下点击“模型管理”。旧导入/校验/空间操作移到独立页面。
- 语音输入法：点击“模型管理”，当前输入会话和未提交预览失效，键盘请求隐藏后打开页面。返回不会恢复旧预览、录音或自动提交。
- App录音未结束时从主页进入，会询问留在主页、停止并等待，或明确取消并离开；管理操作仍须等待共享任务锁释放。
- 管理页不请求麦克风、不自动打开选择器。显示概况只检查内部受管文件；完整 SHA 由显式校验 / 导入末尾或 IME 用户点击录音时按需触发。管理页也可显式准备 / 释放内存模型，IME 则在同一共享 worker 事务内自动准备，不嵌套提交管理任务。

## 导入与重试

1. 准备本项目固定MNN部署目录，或按上述规范生成单个 ZIP；不是原始safetensors或任意压缩包。当前清单7文件，总计1,573,492,181 bytes，界面按清单动态显示。
2. 点击“选择模型目录 / 修复导入”，在系统文件选择器授予只读访问。推荐本地目录；云provider可能联网取文件，App本身无网络权限不等于provider离线。
3. 页面分阶段显示检查已有文件、复制、part校验、发布和最终SHA；复制100%不等于模型安装完成。
4. 完整正确文件可复用，残缺单文件不按字节续传。取消或失败后主动重新选择目录重试；不保存长期目录授权，不自动重试。
5. 预检需求是保守写入预算，并非RAM或未来一定能释放的空间；可用空间可能被其他应用改变。准确所需/检查时可用值在本次预检完成后展示，未知不显示为0。

## 取消与生命周期

- 导入和校验可协作取消；query/read/close可能阻塞，显示取消中时仍持任务锁，不能强行同时开始新操作。
- 发布之前取消先被接受则不发布该文件；发布保留成功后已校验文件可留下，后续边界停止。取消先于最终成功提交则不标READY。
- 旋转/配置重建保留正在运行的进程任务；Home、锁屏或非配置离开会请求取消本页导入/校验。没有后台服务/持续运行承诺。
- 重建后旧目录选择结果拒绝并提示重新选择，不后台自动开始导入。返回页面刷新概况应保留上次用户任务的结果/错误/清理信息。
- 已确认开始删除不支持撤销或取消；离开后仍尝试短列表删除并收尾。系统杀进程后重新检查实际文件，不能保证自动恢复任务。

## 校验、删除与结果保护

- “大小匹配”不是SHA通过。“文件已校验”也不是该设备推理/性能已测。
- 全量校验与 IME 录音前自动校验复用同一持久证明协议及就绪状态。进程重启只接受固定清单、安装锚点、世代及文件身份均匹配的持久证明，不能把历史 true 或大小匹配当免 SHA 凭证；有效证明无需重复全 SHA。
- 删除前再次确认当前模型版本/epoch；忙或模型已变化会拒绝，不排队悄悄删除。
- 仅删除App内部固定文件及明确part名；未知文件、外部源目录、转写文本/原始报告和外部导出均保留。不递归，不安全擦除。
- 部分删除失败显示失败受管文件和剩余概况，不能当作完全删除；再次删除仍需确认。已登记自定义安装即使尚无资产，或资产已删但目录持久写入失败，仍可确认删除/重试以释放安装名额；缺失的旧固定部署不因此开放空删除。安装/目录修订/epoch过期的对话框仍拒绝；未知数据保留、记录不提前移除。
- 模型维护不改App转写正文或ASR结果报告；IME旧预览的提交保护不因此放松。

- [ ] 从主页/IME打开、返回；主页正文保留、IME旧预览不复活。
- [ ] 小屏/横屏/200%字体/手势与三键导航：文字可辨、不透明、底部按钮不被遮挡；TalkBack不被每块IO刷屏。

- [ ] 正确导入→最终校验→App及IME转写；已完整模型再次导入显示全部复用而非复制。
- [ ] 导入/校验中取消、Home、锁屏、旋转、重进：无重复任务，收尾前其他任务被拒绝，结束后恢复可用，错误详情仍在。

- [ ] 确认删除→未安装→重导入；取消删除对话框无副作用，外部源与转写正文保留。
- [ ] 故障注入只在明确授权的测试环境进行；不为验证低空间而自动填满用户设备。

## 仍保留的限制

单固定模型、CPU、App / IME 共享单 resident；不含下载、多模型或后台服务。释放是明确操作 / 既有内存回收策略，非每请求加载与卸载。取消无 provider IO / native 加载硬中止保证；持久证明使用同步写及原子发布，但不承诺七模型文件全或无事务或对恶意外部并发改写者的安全保证。空模型目录删除失败尚未单独显示。外部任务来源提示是App/IME/其他管理页的泛化说明。

Host测试执行生产纯Java组件与provider包装边界，不执行真实ContentResolver/Cursor、Activity、AudioRecord、InputConnection或UI绘制。APK哈希绑定只能检测旧/被修改的派生报告，不替代实际签名工具或防御可同时改写全部证据的攻击者。P0数值/独立语料/性能限制不随本版关闭。
