# 首版离线语音输入法（Phase13）

## 目标与版本

用户确认重构版手动验证无问题后，明确要求优先实现输入法。本轮优先于原模型管理增强路线；拟交付 `0.4-ime-debug`（versionCode 4），不是原计划的0.4模型管理版。当前文档是实施/验收契约，**不代表功能已构建或实机通过**。

## 0.8 候选呈现（尚未交付）

主操作以本地 Canvas Drawable 绘制麦克风、停止、丢弃、确认；工具行保留 App / 上一键盘 / 键盘。每项有中文 contentDescription/tooltip、至少48dp目标；不依赖 emoji/字体图标。App 唯一目标是 Main 首页，不再直达模型；授权在首页→输入法，模型在首页→模型。参见[导航说明](app-navigation.md)。

呈现来自 controller 同步 typed snapshot，不根据中文状态猜 phase：准备未开麦不可停止；录音可停止转写；取消等待收尾仍忙；native 丢弃只作废结果，推理继续至真实 owner 退出；错误默认可见，可明确重置。敏感字段/权限/迟到回调和键盘切换协议不变。预览重录需键盘内两步明确丢弃确认（再点麦克风），不使用缺 Activity token 的 Service 弹窗；字段/会话变化或已观察到权限/shown失效撤销确认，恢复后首点只能再询问。输入预览最多一次，不恢复旧连接/预览。

此轮 host 绘制命令/语义/行为不等 Android 像素、触控、TalkBack 或设备验证。fresh 审查/full/本地提交与新 APK 身份尚待完成。

## 用户流程

1. 在主App完成模型导入/校验，主动授予麦克风权限。
2. 点击输入法设置入口，在Android系统设置中手动启用本输入法；由系统选择器手动切换。不自动更改默认输入法。
3. 正常进程启动在共享 MAINTENANCE worker 自动轻恢复有效模型证明（不做 SHA、不加载 native）。在普通文本框显示语音键盘，选择语言并点击录音：共享 worker 先按需恢复证明，无有效证明则自动完整 SHA-256 校验并持久提交，再加载 / 复用内存模型；全部完成且当前字段、可见性、权限与录音意图仍有效才开麦，最长30秒。缺失或损坏模型不会录音，按提示进入模型管理导入 / 修复。
4. 停止后离线转写，先显示临时预览；仅点击确认才向当前仍有效的输入框提交。
5. 可点击「丢弃 / 重新开始」清除当前会话，或「返回上一输入法」请求 Android 的上一输入法历史；不是全功能拼音/英文键盘。

### 返回上一输入法与选择器

- 从 fcitx5 切入语音键盘仍由用户使用该输入法自己的入口（若有）或 Android 系统输入法选择器；本 App 不修改 fcitx5、不自动启用或更改默认输入法设置。
- 「返回上一输入法」只发起一次系统请求。系统报告接受时不再重复弹选择器；没有历史、拒绝或 RuntimeException 时只尝试一次系统选择器。「切换键盘」始终直接打开选择器。系统历史可能变化，**不保证一定返回 fcitx5**，也不能将请求返回 true 当作系统已完成切换。
- 返回不会代替「确认输入」：未确认预览作废，已确认文本不重发；不自动录音。上一输入法路径先失效旧会话，**不先 hide**，保留平台 show intent；App 与直接选择器路径先失效，再尽力 hide，RuntimeException 也仍尝试明确动作。已进入处理的 native/IO/清理须实际退出后才释放任务 owner。
- 选择器不可用时仅显示通用短提示「暂时无法切换，请使用系统输入法选择入口。」，不展示异常或编辑器正文。取消选择、重选自身或请求失败后，隐藏状态可点击输入框重新显示；若键盘仍可见且系统没有重发窗口回调，可明确点击「丢弃 / 重新开始」创建全新空会话，再手动录音。旧预览不会恢复。
- 重新开始仅在服务存活、控制器可用、键盘实际显示且有当前字段时生效；敏感字段、麦克风权限与忙状态保护仍然有效。不会主动弹出键盘或绕过占用任务。
- 本功能的当批分层验证与未测边界见 [llm-asr-23p 状态](../reports/ime-return-23p/status.md)；fcitx5 往返、厂商系统历史和窗口回调仍须真实设备验证。

## 实现与隐私边界

- InputMethodService与App同进程，复用AppGraph/TaskCoordinator和原CPU native引擎，不创建第二模型实例并发推理。
- 录音只由用户在可见键盘主动点击启动；权限不足时引导主App授权，返回不自动续录。准备、录音、转写分阶段显示；准备时「停止」不可用，可用「丢弃 / 重新开始」取消。全 SHA 可协作取消；native 加载取消须等真实加载返回后才释放共享 owner，不承诺硬中止。
- 已有效的当前证明只轻复核，不反复恢复或卸载；跨进程有效持久证明无需重做 SHA。App / IME 共用唯一进程 resident，已加载则复用，释放后下一次录音可重新准备；不持久化 loaded=true。录音初始化仍在 worker，实际硬件 start 回到主线程同一回调内复核会话 / 字段 / 显示 / 权限，再与 resident release、RecordingControl cancel 线性仲裁；不以早期 Boolean 快照授权开麦。排队 start 超时或中断后禁止迟到执行，已进入实际 start 则等待真实返回再由 worker 清理硬件；adapter 保留最终 gate；普通推理请求不新增 restore/hash/load fallback。
- 输入会话每次开始/重启都重新编号；隐藏、结束输入、解绑或销毁时使旧会话/结果作废。
- 不保存旧InputConnection用于异步提交；确认时在主线程校验当前会话与字段资格，再使用当前连接。失败不自动重试，防止重复插入。
- 密码（文本/可见/web/数字）、TYPE_NULL和请求不个性化学习的字段保守拒绝语音输入。不读取光标前后文字或宿主已有正文。宿主未正确标注的敏感普通文本无法被本App可靠识别。
- IME预览正文/raw不进入App全局识别正文、推理报告、剪贴板或历史；临时请求WAV在同一任务owner内清理。进程异常退出残片由下次受限清理回收，不承诺系统kill时完成删除。
- 键盘隐藏/字段改变时取消录音并丢弃迟到结果；采集结束并提交处理后（包括WAV整理/轻量证明复验，早于JNI进入）不再接受取消，等待实际处理结束才释放owner，不宣称已经中止推理。
- 不增加网络/广泛存储/后台监听权限；系统绑定服务使用BIND_INPUT_METHOD保护，不把它当App申请的运行时权限。
- 继续沿用已审查录音gate；AudioRecord驱动调用可能延迟取消，真实设备释放延迟必须单独验证。

## 自动/源码验收

- 既有245项host基线无回归；新增生产会话/操作组件测试，不复制算法作假覆盖。
- 同字段restart、换字段、隐藏、旧成功/失败回调均不能恢复旧预览或提交。
- 确认票据最多消费一次；连接null/拒绝/异常不得自动重发。
- App/IME任务互斥；App生命周期不能误取消IME采集，IME不能误取消App录音。
- worker开始前取消、采集/推理交接、native返回后旧会话丢弃与owner释放次序覆盖。
- IME流程不写结果报告、不覆盖App原正文；临时文件失败路径有清理。
- Android源码编译、XML资源编译/打包、版本与组件manifest检查、唯一RECORD_AUDIO权限、单DSO/签名/资产校验。
- 冻结源码后独立只读审查，再集中修复并重新构建。host检查不能替代Android服务/连接/音频硬件测试。

## 测试证据边界

host测试执行生产Controller/RequestRunner/TaskCoordinator/RecordingControl及字段策略；fake backend仅证明字节引用转交、会话次序和清理调用/owner，不证明真实WAV→JNI、Android回调或磁盘不可删除。外部UI测试验证生产方法按invalidate→hide命令→launch顺序调用，并模拟新input-view建立，不运行系统选择器。真实Backend、Service、App隐私路径由独立源码追踪和Android编译补充；手机验收仍待执行。

## 用户实机验收清单（新IME尚待验证）

| 场景 | 预期 |
|---|---|
| 覆盖安装、进程冷启动 | App和IME均可初始化，模型仍可使用 |
| 尚未授权麦克风 | 明确引导，无自动录音；拒绝后可再次手动授权 |
| 系统启用/选择与切回 | 用户主动完成；返回上一输入法请求成功不重复弹选择器，无历史/拒绝时一次选择器降级；不保证 fcitx5；取消/重选自身后隐藏可重开字段，仍可见无回调可点「丢弃 / 重新开始」后手动录音，旧预览不恢复 |
| 普通文本框录音→停止→预览→确认 | 确认前不插入，确认后仅一次插入 |
| 校验 / 加载时取消、换字段、换App、收起键盘或权限变化 | 不迟到开麦；耗时任务实际结束前保持互斥 |
| 首次完整文件无证明 / 有效证明冷启动 / 已加载 / 释放后 | 分别自动全 SHA / 轻恢复免 SHA / 内存复用 / 重新准备；缺文件或坏 hash 零录音 |
| 录音时换字段/换App/收起键盘/锁屏 | 取消采集，不向新字段插入，不恢复旧预览 |
| 推理时执行上述切换 | 迟到结果丢弃，完成前任务仍互斥 |
| 同一输入框重新启动输入/旋转 | 保守作废旧票据，不跨会话提交 |
| 密码/数字密码/web密码/敏感标记字段 | 录音与确认不可用，不读取字段正文 |
| App转写时打开IME，反向亦然 | 忙提示，不能并发启动第二次推理 |
| 30秒/取消/连续三次请求 | 正确封顶、状态恢复、无旧结果串入 |
| 切回主App查看结果与导出 | IME正文未进入App当前结果或报告 |

测试使用用户主动选择的非私人测试内容；记录版本/APK hash与设备/Android版本即可，不要求提供私人录音、密码或原文。
