# 0.5 模型管理使用与设备验收

> 当前0.5已完成实现、构建和独立源码复核，可供手动设备验收；不代表设备已通过。最终APK身份以`reports/apk/result.json`和`reports/apk/status.md`为准。详细功能契约见[规划](model-management-plan.md)，实现证据见[验收记录](model-management-validation.md)。

## 页面入口

- 转写主页：模型摘要下点击“模型管理”。旧导入/校验/空间操作移到独立页面。
- 语音输入法：点击“模型管理”，当前输入会话和未提交预览失效，键盘请求隐藏后打开页面。返回不会恢复旧预览、录音或自动提交。
- App录音未结束时从主页进入，会询问留在主页、停止并等待，或明确取消并离开；管理操作仍须等待共享任务锁释放。
- 管理页不请求麦克风、不自动打开选择器、不加载推理模型。显示概况只检查内部受管文件；完整SHA由用户主动校验或转写懒校验触发。

## 导入与重试

1. 准备本项目固定MNN部署目录，而不是原始safetensors或压缩包。当前清单7文件，总计1,573,492,181 bytes，界面按清单动态显示。
2. 点击“选择模型目录 / 修复导入”，在系统文件选择器授予只读访问。推荐本地目录；云provider可能联网取文件，App本身无网络权限不等于provider离线。
3. 页面分阶段显示检查已有文件、复制、part校验、发布和最终SHA；复制100%不等于模型安装完成。
4. 完整正确文件可复用，残缺单文件不按字节续传。取消或失败后主动重新选择目录重试；不保存长期目录授权，不自动重试。
5. 预检需求是保守写入预算，并非RAM或未来一定能释放的空间；可用空间可能被其他应用改变。准确所需/检查时可用值在本次预检完成后展示，未知不显示为0。

## 取消与生命周期

- 导入和校验可协作取消；query/read/close可能阻塞，显示取消中时仍持任务锁，不能强行同时开始新操作。
- 发布之前取消先被接受则不发布该文件；发布保留成功后已校验文件可留下，后续边界停止。取消先于最终成功提交则不标READY。
- 旋转/配置重建保留正在运行的进程任务；Home、锁屏或非配置离开会请求取消本页导入/校验。没有后台服务/持续运行承诺。
- 重建后旧目录选择结果拒绝并提示重新选择，不后台自动开始导入。返回页面刷新概况应保留上次用户任务的结果/错误/清理信息。
- 已确认开始删除不支持撤销或取消；离开后仍尝试短列表删除并收尾。系统杀进程后重新检查实际文件，不能保证自动恢复任务。

## 校验、删除与结果保护

- “大小匹配”不是SHA通过。“文件已校验”也不是该设备推理/性能已测。
- 全量校验或App/IME懒校验共享同一个就绪状态；进程重启不把历史true当免SHA凭证。
- 删除前再次确认当前模型版本/epoch；忙或模型已变化会拒绝，不排队悄悄删除。
- 仅删除App内部固定文件及明确part名；未知文件、外部源目录、转写文本/原始报告和外部导出均保留。不递归，不安全擦除。
- 部分删除失败显示失败受管文件和剩余概况，不能当作完全删除；再次删除仍需确认。
- 模型维护不改App转写正文或ASR结果报告；IME旧预览的提交保护不因此放松。

## 建议人工设备验收顺序（尚未执行）

记录APK SHA、版本、设备型号/Android版本及每项结果；不要提交私人音频、输入框正文或完整源URI到报告。

- [ ] 从主页/IME打开、返回；主页正文保留、IME旧预览不复活。
- [ ] 小屏/横屏/200%字体/手势与三键导航：文字可辨、不透明、底部按钮不被遮挡；TalkBack不被每块IO刷屏。
- [ ] 取消选择、错误目录、缺文件、权限失效、重复/异常provider条目，提示不泄露账户/路径。
- [ ] 正确导入→最终校验→App及IME转写；已完整模型再次导入显示全部复用而非复制。
- [ ] 导入/校验中取消、Home、锁屏、旋转、重进：无重复任务，收尾前其他任务被拒绝，结束后恢复可用，错误详情仍在。
- [ ] 模型管理过程中录音/推理互斥；推理时页面可查看但不可写模型。
- [ ] 确认删除→未安装→重导入；取消删除对话框无副作用，外部源与转写正文保留。
- [ ] 故障注入只在明确授权的测试环境进行；不为验证低空间而自动填满用户设备。

## 仍保留的限制

单固定模型、CPU、每请求释放；不含下载/多模型/后台服务/驻留加速。取消无provider IO时间上限；无fsync断电事务、七文件全或无事务、对恶意外部并发改写者的安全保证。空模型目录删除失败尚未单独显示。外部任务来源提示是App/IME/其他管理页的泛化说明。

Host测试执行生产纯Java组件与provider包装边界，不执行真实ContentResolver/Cursor、Activity、AudioRecord、InputConnection或UI绘制。APK哈希绑定只能检测旧/被修改的派生报告，不替代实际签名工具或防御可同时改写全部证据的攻击者。P0数值/独立语料/性能限制不随本版关闭。
