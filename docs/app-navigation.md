# App 导航与输入法操作（0.8 候选）

本轮在现有 Views、三个 Activity 内整理页面，不新增导航框架或依赖。本文是当前实现契约，不是 APK 交付或设备验收声明；正式包身份以本轮提交后的验证记录为准。

## 唯一入口树

```text
首页
├─ 转写
├─ 模型列表 → 模型详情
├─ 输入法设置
└─ 日志
```

- 首页有“转写 / 模型 / 输入法 / 日志”四个入口。转写页不再堆叠模型、日志和系统设置入口。
- 每个页内“返回”与系统 Back 调用同一生产入口：模型详情→列表→首页；日志、转写、输入法设置→首页。无合法父任务的模型/日志页防御性建立首页后退出，不猜测原宿主。
- 输入法只有一个 App 图标，目标是首页。已有 Main singleTask 收到新 Intent 仅排队归首页请求，在 resume 前台处理；普通 resume 保留当前合法页，不自动重置或开麦。系统可能先 pause，pause 会保守取消未提交录音以防后台/迟到采集：此时只提示已取消等待收尾，不能提供虚假的继续/停止选项；commit 已赢则明确转写继续。
- 模型页不再直达日志，输入法不再直达模型管理。系统授权、启用设置、键盘选择器、文件选择和分享属于外部动作，不是内部导航父节点。

## 任务与返回

转写录音期间主动返回或打开外部界面、且系统尚未先 pause 时，明确选择：继续录音、停止并转写（留在转写页）、丢弃后继续。系统强制 pause 的取消安全动作不等待三选，不承诺外部重入前能先询问。录音确认框只归当前前台生命周期所有：pause 或新首页入口会撤销代次并关闭它，已保存的旧按钮回调也不能停止/取消新任务、重开旧页面或执行旧外部动作；正常选择只消费一次。取消只通知现有 owner，麦克风/worker 真正结束前共享 busy 不变。若取消输给已提交转写，提示任务继续，不能声称中止了 native。

已提交转写、模型删除或外部写入不强制中断；首页任务条保留真实共享忙态和最近状态。首页根 Back 在忙时确认离开，系统仍可能结束进程，不承诺后台持续服务。任务条不根据旧中文状态猜测当前 owner 是 App 或 IME。

模型详情返回列表不取消任务；列表离开只可确认取消本页拥有的导入/校验。取消中需等待真实读取、关闭、清理；删除不可撤销。旁观页不能取消别人。

## 文件选择与重建

- Main 只保存合法逻辑页、语言枚举、WAV 非 capability 高水位；不保存 URI、正文、权限意图、活动票据、proof 或 loaded/owner。
- WAV 使用进程内不复用的 requestCode 20..99，同实例单 pending。只在前台且仍为转写页时消费一次；后台仅同存活实例暂存，离逻辑页、重建、取消、异常均不能恢复旧票据。非法高水位或耗尽 fail-closed，提示重启，不回绕。
- TXT 独立于 ASR busy。离开转写逻辑页撤销尚未提交的选择/排队写入；真实 provider 写入/关闭完成前独立 lane 仍忙，不会提前释放。根级常驻 TXT 排队/写入/失败状态及残留风险，根 Back 在 TXT 忙时也提示离开风险；不因此禁掉 ASR 准入。已经实际开始的外部写入不能撤回，失败可能留下不完整文件。
- 模型继续只保存详情内容键与已有操作 ID；日志不恢复旧导出票据。重建不等于重新授权，不自动重试文件选择或开始业务。

## 简短文案与可见风险

技术说明默认展开按钮收起；进度、当前错误、取消/清理失败、删除风险、导出风险默认可见。模型卡片显示名称、精度声明、大小、当前选用、状态与同安装/epoch 的 x/7，文件 SHA 在详情中查看。“大小匹配”不等于 SHA 通过。

输入法主行使用绘制的麦克风、停止、丢弃、确认图标；工具行是 App、上一键盘、键盘，均保中文描述/tooltip、至少48dp目标。准备尚未开麦不可停止，取消待收尾不可重录；native 只可丢弃结果，不显示“停止推理”。已有预览重录采用键盘内两步确认：先显示丢弃提示，再点麦克风确认；输入框/会话变化，以及已观察到的权限缺失或键盘未显示会撤销确认；恢复资格后首次点击只重新询问，不从 Service 弹 Activity 对话框。失败、敏感字段、权限缺失不隐藏键盘切换入口。

## 验证边界

新 host driver 调用完整当前 Activity/Service、真实 controller 与现有 owner 协议，检查 listener、生命周期、typed presentation 和 Canvas 绘制命令；可编译 mutant 检查目标行为真实失败后恢复。它们不模拟 Android 调度实现，也不证明像素或 TalkBack。

真实任务栈/newIntent/Back dispatcher、系统 SAF/Binder/grant、权限弹窗、48dp实际布局、横屏/大字体、图标识别、TalkBack、输入法历史/fcitx5、麦克风、JNI和模型推理仍须另行授权的设备验证，当前均 NOT RUN。
